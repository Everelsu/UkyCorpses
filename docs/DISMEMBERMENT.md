# Расчленение

Настройки находятся в `config/uky/corpses.cfg`, раздел `dismemberment`. Изменения серверной механики задаёт сервер; `rendering` ограничивает отображение на клиенте. Время в тиках: 20 тиков = секунда. Вероятности 0–1: 0.2 означает 20%.

## Когда оно работает по умолчанию

| Настройка `dismemberment.general` | По умолчанию | Значение |
|---|---|---|
| `enableWhileAlive` | `false` | Несмертельные удары не отсекают части у живых. Нокаут тоже остаётся живым состоянием |
| `enableOnDeath` | `true` | Смертельный удар может отсечь часть в момент смерти |
| `enableWhenDead` | `true` | Уже мёртвому телу можно отсечь часть ударом |
| `enableForPlayers` | `true` | Включить для игроков |
| `enableForMobs` | `true` | Включить для поддерживаемых гуманоидных мобов |

`dismemberment.enabled` дополнительно включает обработку отсечения при ударах по трупам игроков.

Таким образом, живые защищены от несмертельного расчленения, но смертельный удар включён отдельно. Для **строго уже лежащих мёртвых тел** установите `enableOnDeath=false`, оставив `enableWhenDead=true`. Для полного отключения выключите все три переключателя состояний.

## Как выбирается часть

Учитывается попадание и направление атаки. Отсекаются голова, руки и ноги; туловище не отсекается. Уже потерянная часть не выпадает повторно. Отсечённая часть становится самостоятельным физическим объектом: её перетаскивание не тянет туловище. Сохраняются положение частей и маска отсечений.

Шанс — отдельный случайный бросок, а не накопление количества ударов. Броня головы берётся со шлема, рук — с нагрудника, ног — с поножей и ботинок. Доля брони плавно смешивает `baseChanceUnarmored` и `baseChanceArmored`. Итоговый шанс ограничен диапазоном 0–100%.

## Общие условия и полёт частей

Все ключи ниже относятся к `dismemberment.general`.

| Ключ | По умолчанию | Что меняет |
|---|---|---|
| `headshotsCanDecapitate` | `true` | Разрешает отделение головы; `false` запрещает голову во всех состояниях |
| `requireSharpWeapon` | `true` | Для живых и смертельных ударов требуется режущее оружие или подходящий снаряд; у трупов используется порог импульса |
| `bluntWeaponMultiplier` | `0.35` | Множитель шанса тупого оружия при отключённом требовании режущего |
| `fullHelmetArmor` | `3` | Очки шлема, считающиеся полной защитой головы |
| `fullChestplateArmor` | `8` | Полная защита рук нагрудником |
| `fullLegArmor` | `9` | Полная защита ног суммой поножей и ботинок |
| `limbDetachForce` | `1.5` | Скорость отлёта вдоль удара, блоки/сек |
| `limbHopSpeed` | `1.8` | Скорость подброса вверх, блоки/сек |
| `limbTumble` | `6` | Вращение отделённой части, радианы/сек |
| `limbMaxLaunchSpeed` | `5` | Ограничение общей начальной скорости |
| `logAmputations` | `false` | Диагностические записи бросков вероятности в журнал |

## Уже мёртвые тела — `dismemberment.dead`

| Ключ | По умолчанию | Что меняет |
|---|---|---|
| `baseChanceUnarmored` | `0.20` | Базовый шанс без брони |
| `baseChanceArmored` | `0.12` | Базовый шанс при полной броне части |
| `minimumImpulse` | `14` | Более слабые удары не отсекают ничего |
| `impulseReference` | `20` | Импульс, при котором используется полный базовый шанс |
| `limbLifetimeTicks` | `400` | Время жизни отдельно созданной части: 20 секунд; части внутри физического тела также зависят от срока самого тела |
| `cooldownTicks` | `10` | Пауза между отсечениями одного трупа: полсекунды |

Шанс = смешанная по броне база × вес части × импульс / `impulseReference`. Для ручного удара по трупу игрока текущий импульс = min(50, 75 × √(max(1, урон атрибута атаки) / 5)). Поэтому кулак даёт около 33,5, сильное оружие достигает ограничения 50. Это не урон здоровью. При штатном пороге 14 кулак тоже может отсечь часть; чтобы оставить сильные удары, поднимите порог, например, до 40. Голова без брони при импульсе 20: 0.20 × 0.5 = 10%; рука — 20%.

## Смертельный удар — `dismemberment.ondeath`

| Ключ | По умолчанию | Что меняет |
|---|---|---|
| `baseChanceUnarmored` / `baseChanceArmored` | `0.35` / `0.20` | База без брони / с полной бронёй |
| `damageReference` | `8` | Урон для полного базового шанса |
| `overkillBonus` | `0.02` | Добавка за каждую единицу урона сверх оставшегося здоровья, умноженная на вес части |
| `limbLifetimeTicks` | `600` | 30 секунд для отдельно созданной части |
| `maxLimbsPerDeath` | `2` | Верхний предел потерянных частей; не гарантирует их выпадение |

База умножается на вес части и квадратный корень из отношения урона к `damageReference`, затем добавляется бонус избыточного урона. Этот этап можно отключить независимо от ударов по трупам.

## Живые — `dismemberment.alive` (по умолчанию выключено)

| Ключ | По умолчанию | Что меняет после включения `enableWhileAlive` |
|---|---|---|
| `baseChanceUnarmored` / `baseChanceArmored` | `0.08` / `0.04` | Базовые вероятности |
| `minimumDamage` | `4` | Удары слабее 4 единиц не отсекают части |
| `damageReference` | `8` | Урон для полного базового шанса |
| `limbLifetimeTicks` | `1200` | 60 секунд для отдельной части |
| `decapitationMaxHealthFraction` | `0.2` | Голова может отделиться, только если здоровье не выше 20% максимального |
| `decapitationDeathDelayTicks` | `40` | После обезглавливания смерть наступает через 2 секунды; 0 — следующий тик |
| `maxLimbsPerEntity` | `2` | Максимум потерянных частей у живого существа |

Урон в формуле вероятности берётся до брони; броня отдельно уменьшает базовый шанс. Формула: смешанная база × вес части × √(урон / `damageReference`).

## Вес частей и ограничение количества

В `dismemberment.partweights`: `head=0.5`, `leftArm=1.0`, `rightArm=1.0`, `leftLeg=0.7`, `rightLeg=0.7`. Нулевой вес запрещает отсечение конкретной части.

`dismemberment.rendering.maxLooseLimbs=64` ограничивает клиентское количество отдельных частей: при переполнении убираются самые старые. Это не срок жизни инвентаря трупа. Общий жёсткий срок тел с лутом задаётся отдельно: `corpse.performance.corpseLifetimeMinutes`.
