# Настройки крови

Файл: `config/uky/corpses.cfg`. В меню модов эти же параметры доступны через **UkyCorpses → Config → blood**. После редактирования файла вне игры перезапустите клиент. Значения времени ниже указаны в секундах игрового времени.

| Раздел | Параметр | Что меняет |
|---|---|---|
| `blood` | `enabled=true` | Вся система крови |
| `blood.stains` | `stain_lifetime=600` | Пятна исчезают через 10 минут, плавно затухая в последней трети срока |
| `blood.stains` | `dry_time=180` | За сколько свежая кровь темнеет и высыхает; высыхание само по себе не удаляет пятно |
| `blood.stains` | `keep_stains=true` | Сохранять пятна между посещениями мира; выключение не отменяет таймер удаления |
| `blood.stains` | `amount=1.0`, `preset=REALISTIC` | Количество крови; пресеты `MILD`, `REALISTIC`, `EXTREME` |
| `blood.stains` | `footprints=true` | Перенос свежей крови на обуви и лапах |
| `blood.stains` | `footprint_steps=4.0` | Множитель количества следов; меньше значение — короче цепочка |
| `blood.stains` | `footprint_fade=30` | Сколько живут следы; `0` использует общий `stain_lifetime` |
| `blood.stains` | `footprint_shape=SQUARE` | Форма следов: `SQUARE` либо `SHOE` |
| `blood.hit` | `spray`, `mist`, `gouts`, `stream`, `burst` | Брызги, туман, крупные капли, струи и вспышка брызг при попадании |
| `blood.hit` | `spray_speed=1.0`, `droplet_size=1.0` | Скорость/дальность брызг и размер капель |
| `blood.bleeding` | `bleeding=true`, `bleed_amount=1.0`, `bleed_time=1.0` | Продолжающееся кровотечение, его количество и длительность |
| `blood.weapons` | `blood=true` | Загрязнение оружия и инструментов при ударе |
| `blood.weapons` | `coverage=1.0`, `opacity=1.0` | Покрытие и непрозрачность крови на предмете |
| `blood.weapons` | `lasts=300`, `fade=30` | Через сколько начинается стирание крови с оружия и сколько секунд длится плавное исчезновение |
| `blood.weapons` | `hotbar=true`, `drips=true`, `dropped=true` | Кровь на иконке, капли с оружия и сохранение загрязнения при выбрасывании |
| `blood.wounds` | `wounds=true`, `armour=true`, `size=1.0`, `drips=true` | Кровь в месте ранения на коже/броне, размер ран и потёки |
| `blood.wounds` | `spatter=true`, `spatter_lasts=120` | Кровь от попавших на персонажа капель; после полного лечения держится до 120 секунд |
| `blood.performance` | `quality=HIGH`, `max_droplets=2048`, `max_stains=12000`, `render_distance=64` | Нагрузка и дистанция отображения; для слабого ПК можно начать с `quality=LOW` |

Дождь и вода смывают кровь раньше. Лимит `max_stains` удаляет самые старые пятна при переполнении. Пятна учитывают время мира, а не часы Windows: пауза и выключенная игра не расходуют срок.

Кровь на руках видна от первого лица при пустой руке, на теле — от третьего лица и в инвентаре. Загрязнение предметов и персонажей косметическое: оно не записывает новые теги в предметы и не меняет урон, прочность или объединение стаков.

Слабые удары: `blood.stains.weak_hit_damage=4` и `weak_hit_min_scale=0.1` уменьшают брызги и длительность подтекания ниже порога урона. При 1 единице урона остаётся примерно 16% обычного объёма, при 2 — 33%; смертельные удары не уменьшаются.

Попадания снарядов не загрязняют оружие стрелка. Луки и классы дистанционного оружия исключены из покрытия кровью. Сохраняемые пятна находятся в `ukycorpses/blood`; старый кэш переносится автоматически без перезаписи нового.
