# UkyCorpses — Minecraft 1.7.10

Мод объединяет физические тела, нокаут, помощь, расчленение и эффекты крови. Старый вариант сохранён в `backup/pose-animation`.

Физику считает Jolt JNI 6.0.0. Новые трупы — сущности с вещами и опытом; старая драматичная смерть и автоматическое возрождение выключены. Камера связывает игрока, нокдаун и труп по владельцу и идентификатору физической жизни. Она не выбирает ближайшее чужое тело.

## Запуск

Требуется Minecraft 1.7.10 с Forge 1614 и **64-битной Java 8**. lwjgl3ify/RFB для запуска на Java 8 не нужны. Сам движок Jolt 6.0.0 и его нативные библиотеки сохранены; Java-обвязка преобразуется под Java 8 при сборке. Замена `Cleaner` проверяется на явное и автоматическое освобождение объектов.

Библиотека Jolt вложена в JAR мода и подключается после поиска модов Forge. Отдельные моды физики не требуются. Подключение нативной библиотеки проверяется при загрузке; её файлы извлекаются в `ukycorpses/cache` внутри папки игры.

Сборка и проверки:

```powershell
./gradlew.bat build
```

Изолированный клиент разработчика:

```powershell
$env:HOTSWAP='false'
./gradlew.bat runClient -PrunClientWorkingDirectory=run/jolt-port-check --username=JoltCheck
```

`verifyRagdoll` запускает проверки настоящей нативной физики на Java 8. `tools/Run-GameCheck.ps1 -Offline` проверяет игру в отдельном временном мире через обычный `runClient`: тела мобов, физическую камеру игрока, смерть, вещи и возрождение. Также проверяет прогретый Jolt, шейдер крови и нанесение ран через настоящие UV модели моба. Версию Java записывает в `run/portqa-java8/portqa-result.json`. Java для самого Gradle настраивается отдельно от Java игрового процесса.

При создании тела больше не выделяется отдельный неиспользуемый мир Bullet. Нативный Jolt подготавливается при входе игрока и сохраняется до выгрузки мира. На Java 8 выделения при создании снимка тела уменьшились примерно с 501 КБ до 24 КБ. Это измерение конструктора, а не гарантия отсутствия всех задержек.

Кровь включает пятна на поверхностях, брызги, раны, следы и загрязнение оружия. Настройки и таймеры: [BLOOD_SETTINGS.md](docs/BLOOD_SETTINGS.md).

## Управление и настройки

- **H** — включить рэгдолл / подняться; **Shift** запрашивает подъём, если это разрешено настройкой.
- В нокдауне удерживайте **прыжок**, чтобы сдаться; второй игрок удерживает использование для реанимации.
- ПКМ по трупу открывает вещи; Shift + ПКМ перетаскивает выбранную часть.
- Компас после возрождения указывает конкретное тело; операторская команда `/ukycorpses retrieve` восстанавливает содержимое по его идентификатору.

Конфигурация: `config/uky/corpses.cfg`, также доступна через кнопку Config в списке модов. Разделы: `corpse`, `downed`, `effects`, `medicine`, `gameplay`, `blood`, `reactions`, `physics`, `dismemberment`. Старые настройки переносятся автоматически.

## Степень готовности

Успешная сборка и проверки солвера не доказывают полного совпадения поведения. Перенос ещё требует проверки в игре и доработки: все модели мобов и их сочленения, произвольные UV и 3D-предметы, отдельные эффекты жидкостей/шейдеров и поведение в сетевой игре. Адаптеры поршней и обработки урона используют события и классы 1.7.10.

Описание прежней системы находится в [LEGACY_BEHAVIOR.md](docs/LEGACY_BEHAVIOR.md). Оно относится к резервному варианту и не является описанием полной совместимости с оригинальными модами.


### Лимиты тел

Полная памятка по конфигу, ползанию, реакциям, крови, AMP и компасу: [CONFIGURATION.md](docs/CONFIGURATION.md).

Настройки исчезновения крови, брызг, оружия, следов и загрязнения персонажей: [BLOOD_SETTINGS.md](docs/BLOOD_SETTINGS.md).

Категория `corpse.performance`: `playerRagdolls` и `mobRagdolls` независимо включают физику игроков и мобов. Выключение физики игрока сохраняет статический труп с вещами. `corpseLifetimeMinutes` по умолчанию 20: по этому пределу тело и оставшийся лут удаляются окончательно, включая запись восстановления PC. Значение 0 отключает жёсткий предел. Считается игровое время сервера (20 тиков/сек), включая время выгрузки чанка; на паузе и при выключенном сервере таймер не идёт. Старый `ragdollLifetime` остаётся отдельным более коротким временем для пустых трупов и тел мобов.

Расчленение по состояниям, вероятности, броня и времена жизни частей: [DISMEMBERMENT.md](docs/DISMEMBERMENT.md).
